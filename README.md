# ✦ Binky — переводчик всего
Binky переводит любой текст на экране — в играх, комиксах, на сайтах и в видео — прямо поверх оригинала. Обвёл текст — прочитал на своём языке.

## ⬇ Скачать демо

**[Binky Demo 1.6.0 — скачать](https://github.com/GGblinky/Binky/releases/latest)** · Windows 10 / 11 (64-бит)

## ✨ Новое в 1.6.0

🔹 **Интерфейс на трёх языках** — русский, українська, English (выбор прямо в установщике).

🔹 **Всё ставится само** — распознавание русского, украинского и английского текста Binky включает сам.

🔹 **Офлайн-перевод на украинский** и русский — без интернета.

🔹 **Игры на весь экран** (Dota 2, CS2 и др.) — переводит саму игру.

## Что умеет демо

🔹 **Перевод области** — нажми Alt+W и обведи любой текст: перевод появится поверх оригинала.

🔹 **Офлайн-перевод английского** — без интернета, текст никуда не уходит.

🔹 **Сам определяет язык** — ничего настраивать не нужно.

Ограничения демо: 15 переводов подряд, затем перерыв 30 минут. Авто-режим, чат-переводчик для игр, «Что это?» (Википедия), пипетка языка, профили игр и настройки — в полной версии.

## Как установить

Скачай `Binky_Demo_1.6.0.zip` в разделе Releases и распакуй, затем запусти `Install Binky Demo.exe` и выбери язык программы. Уже стоит старая версия — просто установи поверх.

Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».

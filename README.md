# ✦ Binky — переводчик всего
Binky переводит любой текст на экране — в играх, комиксах, на сайтах и в видео — прямо поверх оригинала. Обвёл текст — прочитал по-русски.

## ⬇ Скачать демо

**[Binky Demo 1.5.2 — скачать](https://github.com/GGblinky/Binky/releases/latest)** · Windows 10 / 11 (64-бит)

## Что умеет демо

🔹 **Перевод области** — нажми Alt+W и обведи любой текст: перевод появится поверх оригинала.

🔹 **Офлайн-перевод английского** — без интернета, текст никуда не уходит.

🔹 **Сам определяет язык** — ничего настраивать не нужно.

Ограничения демо: 15 переводов подряд, затем перерыв 30 минут. Авто-режим, чат-переводчик для игр, «Что это?» (Википедия), пипетка языка, профили игр и настройки — в полной версии.

## Как установить

Скачай `Binky_Demo_1.5.2.zip` в разделе Releases и распакуй, затем запусти `Install Binky Demo.exe`.

Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».

# ✦ Binky — переводчик всего
Binky переводит любой текст на экране — в играх, комиксах, на сайтах и в видео — прямо поверх оригинала. Обвёл текст — прочитал на своём языке.

## ⬇ Скачать бесплатно

**[Binky 1.6.1 — скачать](https://github.com/GGblinky/Binky/releases/latest)** · Windows 10 / 11 (64-бит)

Это **полная версия** — со всеми функциями и без ограничений. Бесплатно для всех.

## Что умеет

🔹 **Перевод области** — `Alt+W`: обведи любой текст, и перевод появится поверх оригинала.

🔹 **Авто-режим** — `Alt+A`: Binky сам следит за областью и переводит всё новое — например, чат в Discord или в игре.

🔹 **Чат-переводчик для игр** — `Alt+T`: пишешь на своём языке, в чат игры уходит перевод.

🔹 **«Что это?»** — `Alt+Q`: обведи незнакомое слово — Binky объяснит его по Википедии.

🔹 **Пипетка языка** — `Alt+L`: выдели текст — Binky скажет, какой это язык.

🔹 **Офлайн-перевод** английского на русский и украинский — без интернета, текст никуда не уходит.

🔹 **Игры на весь экран** (Dota 2, CS2 и др.) — переводит саму игру, а не рабочий стол за ней.

🔹 **Интерфейс на трёх языках** — русский, українська, English (выбор прямо в установщике).

🔹 **Всё ставится само** — нужно только нажать «Да», когда Windows спросит разрешение.

Тройной клик по переводу — скопировать. Клавиши меняются в «Меню → Горячие клавиши».

## Как установить

1. Скачай `Binky_1.6.1.zip` в разделе [Releases](https://github.com/GGblinky/Binky/releases/latest) и распакуй.
2. Запусти `Install Binky.exe`.
3. Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».
4. Выбери язык программы и языки текста — готово.

Уже стоит демо или старая версия — просто установи поверх, настройки сохранятся.
